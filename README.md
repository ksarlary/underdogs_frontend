# UnderDogs Frontend

React + Vite frontend for the UnderDogs esports betting project.

## Requirements

- Node.js 22+
- npm

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

The dev server runs on [http://localhost:5174](http://localhost:5174).

## Checks

```bash
npm run lint
npm run build
```
